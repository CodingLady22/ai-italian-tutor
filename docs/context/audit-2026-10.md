# Audit: October 2026

Read-only review of the repo before the public demo. Scope: the checked-out `main` branch, all tracked server and client source. The app was not run; the server Jest suite and ESLint were run read-only. Line numbers are as of the audit date and will drift as fixes land.

Issue numbers `#1`–`#30` are referenced from `AGENTS.md` and `progress-tracker.md`.

Severity: **Critical** / **High** / **Medium** / **Low**. Paths are relative to `app/`.

## Summary

The core path (signup, login, start a session, chat, speak the reply) works on paper but the app is not demo-ready. Four things would show on camera or cost money:

- Rate limiting does nothing: `@Throttle` is applied but the throttler module is never registered.
- A wrong password reloads the page and swallows the error message.
- Email is not implemented on `main`.
- 6 of 7 server test suites fail and the server lint config is broken.

Secrets: `.env` files are git-ignored and absent from the history of all branches (verified).

## Demo guidance

**Show:** landing → signup → login → an A2 *Passato Prossimo* session; a deliberate mistake so the tutor corrects it in the support language; the speaker button; settings (support language, bring-your-own key).

**Avoid until fixed:** a wrong-password login (#2); email verification (#3); voice input outside Chrome/Edge (#19); refreshing a deep link before `vercel.json` is verified (#16); more than 4 messages on the free tier (#5); anything that makes Gemini fail (#6).

**Small features for AI-engineering recruiters:** structured tutor output with `responseSchema` (#15), streaming replies (SSE), an end-of-session summary card.

## Not checked

Mobile layout, production console errors, Railway cold starts and plan, the live Vercel config, and email on any branch other than `main`.
